# Demo Presentation

`Engineering_Drawing_CV_Demo.pptx` contains a 12-slide technical presentation for interviews and portfolio reviews.

Recommended demo flow:

1. Explain the industrial problem.
2. Show a P&ID and identify engineering symbols.
3. Explain the SiED dataset.
4. Explain class imbalance.
5. Show preprocessing.
6. Explain ResNet-18 transfer learning.
7. Show evaluation metrics.
8. Upload a symbol in Streamlit.
9. Show prediction and confidence.
10. Explain API deployment.
11. Discuss production architecture.
12. Close with future detector + OCR + graph extensions.
